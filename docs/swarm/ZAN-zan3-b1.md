## Новые проблемы

Не нашёл. Два наблюдения, не требующих правки в этой итерации:

1. **skipUntilKey без тайм-аута на ключ.** Если после перегрузки декодера ключ не придёт до конца 180-с цикла screenrecord, видео тихо молчит до автоперезапуска (новый поток начинается с SPS/PPS/IDR → самовосстановление ≤180 с). Это следование моему же фиксу из zan2 — риск принят, рестарт гарантирует оживание. Фикс (тайм-аут → фолбэк) — на будущее, не обязательство.
2. В `b1fix2.log:351` «emit exit=1» — артефакт пайпа через `grep -v` (exit code grep при пустом выводе, не tsc): билдер сам это заметил и перегнал без пайпа (`:357`, exit 0). Мой независимый эмит подтверждает exit 0. Не враньё, не проблема кода.

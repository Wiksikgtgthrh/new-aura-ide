# Task Routing

## Масштаб

| Запрос | Маршрут |
|---|---|
| вопрос, мысль вслух, «как думаешь» | ответить, без файлов и задач |
| опечатка, одна правка, один файл | сделать самому + узкая проверка |
| фича в 2–5 файлах | план 3–5 строк → сделать → gates → `code-review` |
| несколько независимых частей, рефактор, новая подсистема | `/fleet`: explorer → planner → builders в worktree → reviewer → qa |
| прод, данные, деплой, SSH-запись | `governance` + `approval-policy`, risk destructive |

Неясно, что хочет человек: один короткий вопрос, а не анкета.

## Скиллы по сигналу

| Сигнал | Скилл |
|---|---|
| UI, лендинг, дашборд, вёрстка | `ui-craft`, потом `visual-qa` |
| дифф, PR, «проверь» | `code-review`, при auth/платежах ещё `security-audit` |
| «выкати», деплой, релиз | `deploy-release` |
| база, миграция, импорт | `data-safety` |
| сервер, VPS, «лежит/тормозит» | `cli-vps`, `observability` |
| поиск в сети, доки | `web-surf` |
| MCP, конфиг агентов | `mcp-setup`, `pi-setup` |
| упало, ошибка, повтор | `failure-recovery` |
| «продолжи», после краша | `session-resume` |
| конец работы по проекту | `session-context` |

## Модели (если есть выбор)

Разведка и рутина на быстрой модели, план, ревью и сложный код на сильной. В Pi задаётся `subagents.agentOverrides.<роль>.model`, в OpenCode `model` в файле агента.

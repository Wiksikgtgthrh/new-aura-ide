# SEO Audit

Агент чинит техническое SEO. Позиции, спрос и ссылки он без данных не знает:
нет доступа к Search Console / Вебмастеру / keyword-API — так и пиши, не выдумывай цифры.

## Чек-лист (проверять в реальном браузере и по HTML ответа, не по исходникам)

1. **Индексация:** `robots.txt`, `sitemap.xml` (все канонические URL, без 404/redirect),
   нет случайного `noindex`, корректные `canonical`, 200 у важных страниц.
2. **Рендеринг:** контент есть в HTML без JS (curl/fetch страницы). Для Next.js — RSC/SSG,
   а не клиентский fetch основного контента.
3. **Метаданные:** уникальные `title` (≤60) и `description` (≤160) на каждую страницу,
   Open Graph + Twitter, OG-картинка 1200x630 (скилл `media-assets`).
4. **Структура:** один `h1`, логичная иерархия `h2–h3`, человекочитаемые URL, хлебные крошки,
   внутренние ссылки на важные страницы, нет сирот.
5. **Schema.org (JSON-LD):** Organization/WebSite, Product/Article/FAQ/BreadcrumbList по типу
   страницы. Валидировать, не только вставлять.
6. **Скорость:** скилл `web-perf` — LCP < 2.5s, INP < 200ms, CLS < 0.1 на мобильном.
7. **Локали:** `hreflang` + `x-default`, `lang` на `<html>`.
8. **Картинки:** `alt`, современные форматы, размеры.

## Контент

- Ключевые слова — только из данных пользователя или реальных источников (поиск через
  SearXNG/Tavily даёт выдачу, но не частотность). Нет данных — помечай как гипотезу.
- Не генерируй пачки «SEO-текстов» ради объёма: это вредит, а не помогает.

# Web Charts — графики без боли

## Выбор библиотеки

- **React + дизайн-система** → `recharts` (дефолт) или `visx` (если нужен
  полный контроль). Не тащи d3 напрямую в React без причины — два хозяина DOM.
- **Тяжёлая аналитика, китайские клиенты, много типов** → `echarts`.
- **Большие данные (>10k точек)** → canvas-based (uPlot, echarts canvas mode);
  SVG умрёт.
- Кастом/уникальная визуализация → d3 как утилиты (scales, shapes), рендер сам.
- **Финансы/свечи/трейдинг** → `lightweight-charts`: свечной график, объёмы,
  crosshair, таймфреймы, обновление последней свечи. Не рисуй финансовый
  график картинкой или самописным SVG, если нужна интерактивность.

## Живые данные

- Значения меняются: flash-up/flash-down на изменении цены/метрики
  (background-color + transition, дёшево), marquee для тикеров.
- Обновления — через подписку/поллинг с разумным интервалом; на скрытой
  вкладке поллинг спит.
- Числа — моноширинным шрифтом (цифры не «пляшут» по ширине).

## Дизайн графика

- Цвета — из токенов темы (CSS-переменные), не хардкод hex. Light/dark обе.
- Сетка: тонкая, приглушённая (opacity 0.1–0.2), не чёрные полосы.
- Оси: минимум подписей, формат чисел человеческий (12k, не 12000).
- Тултип: в стиле сайта, не дефолтный браузерный/библиотечный.
- Легенда — если серий больше одной; одна серия — подпись в заголовке.
- Пустые данные / загрузка / ошибка — три состояния, не пустой прямоугольник.

### Типографика осей — без мыла

Подписи осей читаются на скриншоте так же чётко, как интерфейс вокруг:

- Шрифт осей = моноширинный из токенов (`--font-mono`), не дефолт библиотеки.
  Для lightweight-charts: `layout.fontFamily` + `fontSize` ≥ 11.
- Цвет подписей — не ниже `--ink-soft` по контрасту; проверь на скриншоте
  в обеих темах. «Еле видно» = брак.
- Даты локализованы: `localization: { locale: 'ru-RU', ... }` — не «Oct '26»
  на русскоязычном продукте.
- Цена у курсора и последняя цена на шкале — с бейджем-фоном (labelBackground
  из токенов), текст бейджа контрастен фону.
- Скриншот-гейт: открой график крупно (zoom/crop) — мыльные или обрезанные
  подписи осей ловятся только глазами, не кодом.

## Responsive и доступность

- График переживает 375px: горизонтальный скролл оси допустим, обрезанный
  тултип — нет.
- Данные дублируются: таблица/текстовая сводка для скринридера
  (`aria-label` + sr-only таблица).
- Не кодируй смысл только цветом — различие форм/паттернов/подписей.

## Антипаттерны

- 3D-пироги и градиентные столбики — выкинуть.
- Анимация появления > 1 с или при каждом ховере — раздражает.
- Pie с > 6 секторами — это bar chart, ты просто не знал.

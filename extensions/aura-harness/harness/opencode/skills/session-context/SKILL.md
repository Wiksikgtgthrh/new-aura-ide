# Session-Context — выжимки сессий

Живой контекст работы: что делали, что решили, где наступили на грабли. Чтобы
следующая сессия входила в курс без «а что тут вообще было».

## Когда писать — правило по оси «проект / не проект»

Спам не плодим. Иначе каждая сессия превращается в файл, и мы становимся
ресёрч-машиной.

- **Работа по проекту** (есть реальная папка в `~/Projects/<проект>`) → пиши
  выжимку **сам, не спрашивая**, в `Session-Context/Projects/<проект>/`.
- **Работа без проекта** (ресёрч, разборы, настройка, разговор) → **сам не пишу**.
  Только по команде `/итог` или прямой просьбе. Сомневаешься — не пиши, спроси
  одной строкой: «записать?».
- Если просили и проект не при чём → папка дня
  `Session-Context/<год>/<месяц>/<день>/`.

**Не путать со складами:** в `MEMORY/<дата>` — только то, что останется правдой и
завтра (пути, установки, настройки, решения по хозяйству), не «что делали». Лента
работы — сюда, в `Session-Context`.

**Микро-пост (минимум, если работа была небольшая):**

```markdown
# <Тема>: <коротко>

Выжимка сессии. <дата>. <машина>.

## Что делали
- По шагам, с конкретикой.

## Живая верифа
- Что реально запустили и увидели.

## Что осталось
- Следующий шаг.
```

Большая работа — полный шаблон ниже.

## Где (корень — `Session-Context/`)

- Windows: `%USERPROFILE%\Session-Context\`
- Linux/macOS: `$HOME/Session-Context/`

## Разделение внутри

```
Session-Context/
├── Projects/
│   └── <имя папки проекта>/          ← если есть реальная папка проекта
│       └── <ГГГГ-ММ-ДД-слаг>.md
├── Journal/                          ← журнал: строки «что сделали за день»
│   └── <ГГГГ>/<ММ>/
│       ├── <ДД>.md
│       └── <ДД>/                     ← если день перевалил 500 строк
│           └── <ДД>.N.md
└── <ГГГГ>/
    └── <ММ>/
        └── <ДД>/                      ← папка дня, внутри сколько угодно md
            ├── <слаг>.md
            └── ...
```

- **Проект** (есть реальная папка проекта в `Projects/`) →
  `Session-Context/Projects/<имя папки проекта>/<дата-слаг>.md`.
  Имя папки — **точное**, как у проекта.
- **Всё остальное** (не проект, или папки проекта нет) →
  `Session-Context/<год>/<месяц>/<день>/` — **папка дня**, внутри куча md.

## Имя файла

`ГГГГ-ММ-ДД-короткий-слаг.md` — дата = день, когда реально копошились.

## Что писать (шаблон)

```markdown
# <Тема>: <коротко о чём>

Выжимка сессии. <дата>. <ОС/машина>.

## Цель
- Что хотели сделать.

## Что сделали
- По шагам, с конкретикой (файлы, команды, ветки).

## Решения (и почему)
- Что выбрали и почему; что отклонили.

## Живая верифа
- Что реально запустили и увидели (не «должно работать»).

## Грабли
- Где споткнулись и как вылезли.

## Что осталось
- Следующий шаг.

## Артефакты
- Коммиты/ветки/файлы/сервисы.
```

## Правила

- **По фактам.** Отделяй факт / вывод / гипотезу.
- **Живая верифа** — писать только то, что реально проверили.
- Пути — через `~` (переносимость на другую машину).
- Секреты (пароли, токены, ключи) в выжимку **не тащить**.
- Проект → `Projects/<имя>/`; не проект → `<год>/<месяц>/<день>/`.
- Не плоди файлы на каждый чих: дописывай, заводи новый когда началась новая тема/день.
- Журнал — отдельное дерево `Journal/`, **не** в `README.md`. Строку добавляй при
  каждой выжимке (см. ниже).
- В `README.md` журнал **не ведём** — там только описание структуры.

## Журнал (`Journal/`)

Короткая летопись «что сделали за день», отдельно от самой выжимки. Живёт только
в `Session-Context/Journal/`.

- Формат строки: `- ГГГГ-ММ-ДД — <что сделали / что решили>`.
- Файл дня: `Journal/<год>/<месяц>/<день>.md` (напр. `Journal/2026/09/27.md`),
  внутри шапка `# Журнал — <ГГГГ-ММ-ДД>` и строки.
- Докуда влезает — держим одним файлом дня.
- **Файл дня перевалил 500 строк** → день становится папкой
  `Journal/<год>/<месяц>/<день>/` и режется на части `<день>.N.md` по ≤500 строк
  (напр. `Journal/2026/09/27/27.1.md`).
- **Ссылка на выжимку.** Если под событие есть выжимка — дописывай в конец строки
  ссылку относительным путём: `→ [файл.md](../../../2026/09/27/файл.md)` (из
  `Journal/<год>/<месяц>/` до корня `Session-Context/` — три уровня `../../../`).
  Журнал = **оглавление**, выжимка = полный текст. Нет выжимки — строка живёт сама.
- Добавляй строку в тот же день, что и выжимку. В `README.md` — ничего не пишем.

## Быстро завести

Проект (Linux/macOS):
```bash
P="$HOME/Session-Context/Projects/<имя>"; mkdir -p "$P"
$EDITOR "$P/$(date +%F)-slova.md"
```

Не проект (папка дня, Linux/macOS):
```bash
D="$HOME/Session-Context/$(date +%Y/%m/%d)"; mkdir -p "$D"
$EDITOR "$D/$(date +%F)-slova.md"
```

Windows (pwsh), проект:
```powershell
$p = "$env:USERPROFILE\Session-Context\Projects\<имя>"
New-Item -ItemType Directory -Force $p | Out-Null
New-Item "$p\$(Get-Date -Format yyyy-MM-dd)-slova.md"
```

Windows (pwsh), папка дня:
```powershell
$d = Get-Date
$p = "$env:USERPROFILE\Session-Context\$($d.ToString('yyyy'))\$($d.ToString('MM'))\$($d.ToString('dd'))"
New-Item -ItemType Directory -Force $p | Out-Null
New-Item "$p\$($d.ToString('yyyy-MM-dd'))-slova.md"
```

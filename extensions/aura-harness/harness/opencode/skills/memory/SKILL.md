# MEMORY — карта и дневник

Память живёт **в корне системы** и делится на два уровня: карта (`MEMORY.md`) и
дневник (`MEMORY/<год>/<месяц>/<день>.md`). Карта — статичная, дневник — факты по
дням. Скилл заводит это сам.

## Где (корень системы)

Пути — **по своей ОС**, чужие не таскать:

| ОС | Карта | Дни |
|---|---|---|
| Windows | `%USERPROFILE%\MEMORY.md` | `%USERPROFILE%\MEMORY\<ГГГГ>\<ММ>\<ДД>.md` |
| Linux/macOS | `$HOME/MEMORY.md` | `$HOME/MEMORY/<ГГГГ>/<ММ>/<ДД>.md` |

## Уровень 1 — `MEMORY.md` (карта)

```markdown
# MEMORY

## Железо и система
- ОС, оболочка (напр. Windows, PowerShell/pwsh), пользователь.
- Что есть и чего нет (напр. нет WSL — только виндовые пути).

## Пользователь
- Кто, профиль.

## Пути (главное)
| Что | Где |
|---|---|
| Память (карта) | `~/MEMORY.md` |
| Дневник | `~/MEMORY/<ГГГГ>/<ММ>/<ДД>.md` |
| Инструкция | `~/AGENTS.md` |
| Сводка | `~/AGENTS-SUMMARY.md` |
| Проекты | `~/Projects/<проект>` |
| Выжимки сессий | `~/Session-Context/Projects/<проект>/`, иначе `~/Session-Context/<год>/<месяц>/<день>/` |
| Журнал | `~/Session-Context/Journal/<год>/<месяц>/<день>.md` |
| Скиллы | папка скиллов текущего агента: ZCode `~/.zcode/skills/`, opencode `~/.config/opencode/skills/`, общая `~/.agents/skills/` |
```

`MEMORY.md` — **статичная карта**: меняется редко (смена железа, пользователя, путей).
Вехи и решения — в дневнике.

## Уровень 2 — дневник

`MEMORY/<ГГГГ>/<ММ>/<ДД>.md` — по дню. Пишем **в текущий день**, не в общий файл.
Только то, что останется правдой и завтра: что поставили, что куда переехало, как
теперь настроено, какие решения приняли. **Не** «что делали за день» — лента работы
живёт в Session-Context, не здесь.

### Дробление: файл растёт — становится папкой

Держим дневной файл **≤ 500 строк**. Как только перевалило:

1. День превращается в **папку**: `MEMORY/<ГГГГ>/<ММ>/<ДД>/`.
2. Содержимое режется на части по **≤ 500 строк**: `ДД.1.md`, `ДД.2.md`, `ДД.3.md`, …
3. Одиночный `ДД.md` в этом случае больше **не используем** — источник правды теперь папка дня.

```
MEMORY/2026/09/26.md          ← пока ≤ 500 строк
MEMORY/2026/09/26/            ← перевалило 500 → папка дня
├── 26.1.md                   ≤ 500 строк
├── 26.2.md                   ≤ 500 строк
└── ...
```

- Нумерация с `1`, по порядку. Дописываем в **последнюю** часть; переполнилась — заводим следующую.
- Старые части без нужды не переписываем.

## Правила (скилл заставляет вести)

- Заводи `MEMORY.md` и папки **сам**, если их нет.
- Дату бери из системы. Пиши в **текущий день**.
- **В начале работы** — загляни в `MEMORY.md`: в курсе ли ты о железе/путях.
- **В конце работы** — допиши в дневник, **только если появились факты о хозяйстве** (что поставили/переехало/как настроено). Фактов нет — записи нет.
- Дневной файл **> 500 строк** → день становится папкой и режется на части `ДД.N.md` (см. «Дробление»).
- `MEMORY.md` — карта: трогаем редко (железо/пользователь/пути). Вехи и решения — в дневник.
- Секреты (пароли, токены, ключи) в память **не тащить**.
- Факт / вывод / гипотезу держать раздельно.

## Быстро завести

С нуля на новой машине: сперва карта `MEMORY.md`, потом папка и файл текущего дня.

### Карта `MEMORY.md`

Linux/macOS:
```bash
cat > "$HOME/MEMORY.md" <<'EOF'
# MEMORY

## Железо и система
- ОС, оболочка, пользователь. Что есть и чего нет.

## Пользователь
- Кто, профиль.

## Пути (главное)
| Что | Где |
|---|---|
| Память (карта) | `~/MEMORY.md` |
| Дневник | `~/MEMORY/<ГГГГ>/<ММ>/<ДД>.md` |
| Инструкция | `~/AGENTS.md` |
| Сводка | `~/AGENTS-SUMMARY.md` |
| Проекты | `~/Projects/<проект>` |
| Выжимки сессий | `~/Session-Context/Projects/<проект>/`, иначе `~/Session-Context/<год>/<месяц>/<день>/` |
| Журнал | `~/Session-Context/Journal/<год>/<месяц>/<день>.md` |
| Скиллы | папка скиллов текущего агента: ZCode `~/.zcode/skills/`, opencode `~/.config/opencode/skills/`, общая `~/.agents/skills/` |
EOF
```

Windows (pwsh):
```powershell
@'
# MEMORY

## Железо и система
- ОС, оболочка, пользователь. Что есть и чего нет.

## Пользователь
- Кто, профиль.

## Пути (главное)
| Что | Где |
|---|---|
| Память (карта) | `%USERPROFILE%\MEMORY.md` |
| Дневник | `%USERPROFILE%\MEMORY\<ГГГГ>\<ММ>\<ДД>.md` |
| Инструкция | `%USERPROFILE%\AGENTS.md` |
| Проекты | `%USERPROFILE%\Projects\<проект>` |
| Выжимки сессий | `%USERPROFILE%\Session-Context\Projects\<проект>\` |
'@ | Set-Content "$env:USERPROFILE\MEMORY.md" -Encoding utf8
```

Файл уже есть — **не перезаписываем**, только дополняем/уточняем. Пути — по своей ОС.

### Папка и файл дня

Linux/macOS:
```bash
mkdir -p "$HOME/MEMORY/$(date +%Y/%m)"
touch "$HOME/MEMORY/$(date +%Y/%m/%d).md"
```

Windows (pwsh):
```powershell
$d = Get-Date
$dir = "$env:USERPROFILE\MEMORY\$($d.ToString('yyyy'))\$($d.ToString('MM'))"
New-Item -ItemType Directory -Force $dir | Out-Null
New-Item -ItemType File -Force "$dir\$($d.ToString('dd')).md" | Out-Null
```
